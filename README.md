# YouTube → FreeTube v1.0

Automatically redirects supported YouTube video links to [FreeTube](https://freetubeapp.io/) instead of opening them in YouTube.

## Features

- YouTube videos, Shorts, and `youtu.be` links → FreeTube
- Works with links opened from other applications
- Automatically closes blocked YouTube tabs after 1 second
- No tracking, analytics, advertisements, external servers, or accounts
- Open source

## Requirements

- Chromium-based browser with Manifest V3 support
- [FreeTube](https://freetubeapp.io/) installed
- `freetube://` protocol support

## Installation

1. Install [FreeTube](https://freetubeapp.io/).
2. Download and extract the latest release from the [Releases](https://github.com/Mangaz7/youtube-freetube/releases) page.
3. Open `chrome://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked** and select the extracted folder.

## Compatibility

Compatible with Chromium-based browsers supporting Manifest V3, including Chrome, Chromium, Brave, and Helium.

FreeTube supports Windows, macOS, and Linux.
